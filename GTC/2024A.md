## 🌟 Q1 (i) Suppose $G$ is a non-directed graph with 12 edges. If 6 vertices are each of degree 3 and the rest are degree less than 3, what is the minimum number of vertices in $G$?

✨ **Answer:**

🔹 **Given:**
* Number of edges: $|E| = 12$
* 6 vertices each have a degree of 3.

🧠 **Apply Handshaking Lemma:**
According to the Handshaking Lemma:
$$\sum \deg(v) = 2|E|$$

Therefore:
$$\sum \deg(v) = 2(12) = 24$$

🔥 **Degree Contribution of Given 6 Vertices:**
Each of the 6 vertices has a degree of 3.
So the total degree contributed is:
$6 \times 3 = 18$

🔍 **Remaining Degree Sum:**
Remaining degree sum:
$24 - 18 = 6$

Now:
* All remaining vertices must have a degree of less than 3.
* To minimize the number of vertices, we must maximize their degrees.

The maximum possible degree less than 3 is: **2**.

🧠 **Minimum Remaining Vertices:**
To obtain a degree sum of 6 using vertices of degree 2:
$\frac{6}{2} = 3$

So the minimum additional vertices required is 3.

🌟 **Total Minimum Vertices:**
$6 + 3 = 9$

✅ **Final Answer:**
🌟 Minimum number of vertices = **9**

## 🌟 Q2 (ii) Prove that “Every connected graph has a spanning tree.”

✨ **Answer:**

🔹 **Spanning Tree:**
A spanning tree:
* contains all vertices.
* is connected.
* has no cycles.

🧠 **Proof:**
Suppose $G$ is a connected graph.

If the graph has no cycles:
* then the graph itself is already a tree, and it serves as its own spanning tree.

If the graph contains cycles:
* remove one edge from a cycle.
* Removing one edge from a cycle does not disconnect the graph.

Repeat this exact process until all cycles are systematically removed.
The resulting graph:
* remains connected.
* contains all vertices.
* has no cycles.

Hence, it perfectly becomes a spanning tree.

🌈 **Example:**

    A ----- B
    | \     |
    |  \    |
    D ----- C

This graph contains a cycle. Let's remove edge $AC$.

Result:

    A ----- B
    |       |
    |       |
    D ----- C

Now it is:
* connected.
* contains no cycles.
* includes all vertices.

Hence, a spanning tree is successfully obtained.

✅ **Final Conclusion:**
Every connected graph always has at least one spanning tree.

## 🌟 Q2 (iii) A rooted tree has $n$ vertices and $k$ pendant vertices. Find the number of vertices having degree 3.

🔹 **Definitions:**
* Pendant vertex: degree = 1.
* Suppose the number of vertices having a degree of 3 is $x$.

For any tree, the sum of degrees is:
$$\sum \deg(v) = 2(n-1)$$

🔥 **Assume Remaining Vertices Have Degree 2:**
Vertices breakdown:
* $k$ pendant vertices of degree 1.
* $x$ vertices of degree 3.
* remaining vertices of degree 2.

The number of remaining vertices is:
$n - k - x$

🔥 **Degree Sum Equation:**
$$k(1) + 3(x) + 2(n - k - x) = 2(n - 1)$$

Expand the equation:
$$k + 3x + 2n - 2k - 2x = 2n - 2$$
$$x - k + 2n = 2n - 2$$
$$x - k = -2$$
$$x = k - 2$$

✅ **Final Answer:**
🌟 Number of degree 3 vertices:
$$x = k - 2$$

      | /   \ |

We need to remove at least 3 vertices to disconnect it.
Hence: $K(G) = 3$

🔥 **Edge Connectivity:**
We need to remove at least 3 edges to disconnect it.

🌟 **Verification:**

Vertex connectivity can never exceed edge connectivity.

## 🌟 Q4 (i) “A graph is 2-colorable if it is bipartite and every cycle has an even length.” Justify this with a suitable example.

✨ **Answer:**

🔹 **2-Colorable Graph:**
A graph is said to be 2-colorable if:
* only two colors are enough to color all vertices. 🎨
* no two adjacent vertices receive the same color.

🔹 **Bipartite Graph:**
A graph is bipartite if:
* vertices can be divided into two disjoint sets.
* edges connect vertices only from different sets.

🧠 **Fundamental Theorem:**
✅ A graph is bipartite if and only if every cycle has an even length. This theorem is extremely important in graph coloring.

🔥 **Why Odd Cycles Fail:**
Suppose we try to color a triangle:

      A
     / \
    B---C

Cycle length is 3, which is odd.
Try using two colors:
* A = Red
* B = Blue
* C must differ from B $\to$ Red

But now $A$ and $C$ both become Red, and they are adjacent! ❌
Hence, odd cycles are fundamentally not 2-colorable.

🌈 **Suitable Example of 2-Colorable Graph:**
Consider a square graph:

    A ----- B
    |       |
    |       |
    D ----- C

This is a cycle $C_4$. Length is 4, which is EVEN ✅

🎨 **Proper Coloring:**
Assign colors:
| Vertex | Color |
| :--- | :--- |
| A | 🔴 |
| B | 🔵 |
| C | 🔴 |
| D | 🔵 |

No adjacent vertices have the same color.
Thus, the graph is bipartite and perfectly 2-colorable.

🎯 **Final Conclusion:**
A graph is 2-colorable exactly when it is bipartite and every cycle has an even length.

## 🌟 Q6 (ii) Using generating functions, find $a_n$ in terms of $n$ for the recurrence relation: $a_0 = 1, a_1 = 2$ and $a_{n+2} = 5a_{n+1} - 4a_n, \quad n \geq 0$

✨ **Answer:**

🔹 **Step 1: Assume Generating Function**
Let:
$$A(x) = a_0 + a_1x + a_2x^2 + \cdots$$

We are given the linear recurrence relation:
$$a_{n+2} = 5a_{n+1} - 4a_n$$

🔥 **Step 2: Form Characteristic Equation**
Convert the recurrence relation directly into its characteristic equation:
$$r^2 - 5r + 4 = 0$$

Factorize:
$$(r - 4)(r - 1) = 0$$

Roots:
$$r = 4, \quad r = 1$$

🔥 **Step 3: General Solution**
Since the roots are perfectly distinct:
$$a_n = A(4^n) + B(1^n)$$
$$a_n = A(4^n) + B$$

🔥 **Step 4: Use Initial Conditions**
Using $a_0 = 1$:
$$A + B = 1$$

Using $a_1 = 2$:
$$4A + B = 2$$

Subtract the equations:
$$(4A + B) - (A + B) = 2 - 1$$
$$3A = 1$$
$$A = \frac{1}{3}$$

Now solve for $B$:
$$B = 1 - \frac{1}{3}$$
$$B = \frac{2}{3}$$

🔥 **Step 5: Final Formula**
Substitute the values back in:
$$a_n = \frac{1}{3}(4^n) + \frac{2}{3}$$

✅ **Final Answer:**
$$a_n = \frac{4^n + 2}{3}$$

🌈 **Verification:**
For $n=0$:
$$a_0 = \frac{1+2}{3} = 1$$ (Correct ✅)

For $n=1$:
$$a_1 = \frac{4+2}{3} = 2$$ (Correct ✅)

🎯 **Final Conclusion:**
The required explicit formula is definitively:
🌟 $$a_n = \frac{4^n + 2}{3}$$
