## 🌟 Q1 (ii) Find out the maximum and minimum number of edges in a 3-component graph having 10 vertices.

✨ **Answer:**

🔹 **Given:**
* Number of vertices: $n = 10$
* Number of components: $k = 3$

🌟 **Minimum Number of Edges**
For minimum edges, every component should be a tree. 🌳
We know that for a graph with $k$ components, the minimum number of edges is:
$$|E|_{min} = n - k$$

Substitute the values:
$10 - 3 = 7$

✅ Minimum Edges: 🌟 **7**

🌟 **Maximum Number of Edges**
To maximize the edges:
* Make one component as large a complete graph as possible.
* Keep the remaining components as isolated single vertices.

So, the largest component has:
$10 - (3 - 1) = 8$ vertices.

The maximum number of edges in a complete graph is given by:
$$\frac{n(n-1)}{2}$$

Hence:
$$\frac{8(7)}{2} = 28$$

✅ Maximum Edges: 🌟 **28**

🎯 **Final Answer:**
| Quantity | Answer |
| :--- | :--- |
| Minimum edges | **7** |
| Maximum edges | **28** |

## 🌟 Q2 (ii) Prove with a suitable example: “Every tree has either one or two centers”.

✨ **Answer:**

🔹 **Center of a Tree**
The center of a tree is the vertex having the minimum eccentricity.

🔹 **Eccentricity**
The eccentricity of a vertex is the maximum distance from that vertex to any other vertex in the tree.

🧠 **Theorem**
Every tree has either one center OR two adjacent centers.

🌈 **Example 1: One Center**

    A — B — C — D — E

**Distances:**
| Vertex | Maximum Distance (Eccentricity) |
| :--- | :--- |
| A | 4 |
| B | 3 |
| C | 2 |
| D | 3 |
| E | 4 |

The minimum eccentricity is at vertex $C$.
Hence, this tree has exactly one center.

🌈 **Example 2: Two Centers**

    A — B — C — D

**Eccentricities:**
| Vertex | Max Distance |
| :--- | :--- |
| A | 3 |
| B | 2 |
| C | 2 |
| D | 3 |

The minimum eccentricity is at vertices $B$ and $C$.
Hence, there are two adjacent centers.

🎯 **Final Conclusion:**
Every tree always contains exactly one center OR two adjacent centers.

## 🌟 Q3 (iii) Justify this using a suitable example: “The vertex connectivity of any graph $G$ can never exceed the edge connectivity of $G$.”

✨ **Answer:**

🔹 **Vertex Connectivity**
Vertex connectivity, denoted by $K(G)$, is the minimum number of vertices whose removal disconnects the graph.

🔹 **Edge Connectivity**
Edge connectivity, denoted by $\lambda(G)$, is the minimum number of edges whose removal disconnects the graph.

🧠 **Important Theorem**
For every connected graph:
$$K(G) \leq \lambda(G)$$
Meaning: 👉 Vertex connectivity can never exceed edge connectivity.

🌈 **Suitable Example**
Consider a complete graph $K_4$:

      A ----- B
      |\     /|
      | \   / |
      |  \ /  |
      |  / \  |
      | /   \ |
      |/     \|
      C ----- D

🔥 **Vertex Connectivity**
To disconnect $K_4$, at least **3** vertices must be removed.
Hence: $K(G) = 3$

🔥 **Edge Connectivity**
To disconnect the graph, at least **3** edges must be removed.
Hence: $\lambda(G) = 3$

🌟 **Verification**
$K(G) = \lambda(G)$
Thus, $K(G) \leq \lambda(G)$ is perfectly satisfied! ✅

🧠 **Why This Theorem is True:**
Removing a vertex automatically removes all incident edges with it. So disconnecting a graph by removing vertices is usually easier (or equally difficult) compared to disconnecting it only by removing edges.

🎯 **Final Conclusion:**
For every connected graph, $K(G) \leq \lambda(G)$. Hence proved with a suitable example.

## 🌟 Q4 (i) “A graph is 2-colorable if it is bipartite and every cycle has an even length.” Justify this with a suitable example.

✨ **Answer:**

🔹 **2-Colorable Graph**
A graph is called 2-colorable if:
* only two colors are sufficient. 🎨
* adjacent vertices receive different colors.

🔹 **Bipartite Graph**
A graph is bipartite if:
* vertices can be divided into two disjoint sets.
* edges exist only between the sets.

🧠 **Fundamental Theorem**
✅ A graph is bipartite iff every cycle has an even length.
Why? Because odd cycles force a same-color conflict ❌, while even cycles allow alternating coloring. ✅

🌈 **Example of Bipartite Graph**
Consider a square cycle $C_4$:

    A ----- B
    |       |
    |       |
    D ----- C

Cycle length: **4**, which is EVEN ✅

🎨 **2-Coloring**
Assign colors:
| Vertex | Color |
| :--- | :--- |
| A | 🔴 |
| B | 🔵 |
| C | 🔴 |
| D | 🔵 |

No adjacent vertices have the same color. ✅
Thus, the graph is bipartite and 2-colorable.

❌ **Example of Non-Bipartite Graph**
A Triangle:

      A
     / \
    B---C

Cycle length: **3**, which is odd ❌
Using only 2 colors becomes logically impossible here.

🎯 **Final Conclusion:**
A graph is 2-colorable exactly when it is bipartite and all cycles are even.

## 🌟 Q4 (ii) If a graph has 100 vertices and 300 edges, can it be planar?

✨ **Answer:**

🔹 **Planar Graph Condition**
For any simple connected planar graph:
$$e \leq 3v - 6$$
Where:
* $e$ = number of edges
* $v$ = number of vertices

🔍 **Given**
* $v = 100$
* $e = 300$

🔥 **Apply Formula**
$3(100) - 6 = 300 - 6 = 294$

For this to be a planar graph, we must have:
$$e \leq 294$$

But we are given $e = 300$, which is strictly greater than **294**. ❌

❌ **Therefore:**
The graph cannot be planar.

✅ **Final Answer:**
A graph with **100** vertices and **300** edges cannot be planar because it violates the fundamental planar graph condition.

## 🌟 Q5 (i) How many cards must be selected from a standard deck of 52 cards to guarantee that at least three hearts are selected?

✨ **Answer:**

🔹 **Use Pigeonhole Principle 🐦**
A standard deck contains:
* **13** hearts ❤️
* **39** non-hearts

🧠 **Worst Case Scenario**
To systematically avoid getting 3 hearts for as long as possible:
* First, select all **39** non-hearts.
* Then, select exactly **2** hearts.

Total cards selected without guaranteeing 3 hearts:
$39 + 2 = 41$

Therefore, selecting just one more card guarantees you will draw 3 hearts.

✅ **Final Answer:**
$41 + 1 = 42$
🌟 **42 cards** must be selected.

## 🌟 Q5 (ii) How many ways are there for eight men and five women to stand in a line so that no two women stand next to each other?

✨ **Answer:**

🔹 **Step 1: Arrange Men**
Arrange 8 men: $8!$ ways.

🔹 **Step 2: Create Gaps**
After arranging the men, the gaps available are:
`_ M _ M _ M _ M _ M _ M _ M _ M _`

Number of available gaps: **9**

🔹 **Step 3: Choose Positions for Women**
Choose 5 gaps from the 9 available:
$\binom{9}{5}$

🔹 **Step 4: Arrange Women**
Arrange the 5 women in those chosen gaps: $5!$

🔥 **Total Arrangements**
$$8! \times \binom{9}{5} \times 5!$$
$$= 40320 \times 126 \times 120$$
$$= 609638400$$

✅ **Final Answer:**
🌟 **609,638,400 ways**
