## 🌟 Q1 (ii) Prove that “If a graph has exactly two vertices of odd degrees, there must be a path joining these two vertices.”

✨ **Answer:**

🔹 **Important Theorem:**
In every graph, the number of odd-degree vertices is always even. This fundamentally follows from the Handshaking Lemma.

🔹 **Given:**
The graph contains exactly two odd-degree vertices. Let them be $u$ and $v$.

🧠 **Proof:**
Suppose no path exists between $u$ and $v$. This means that $u$ and $v$ must belong to entirely different connected components of the graph.

🔥 **Apply Odd Degree Property to Components:**
In every individual connected component, the number of odd-degree vertices must be an even number. 
But under our assumption:
* One component contains only $u$ (exactly **1** odd-degree vertex).
* Another component contains only $v$ (exactly **1** odd-degree vertex).

Each of these components now has an odd number of odd-degree vertices, which is completely impossible! ❌ Odd-degree vertices must always occur in pairs within any component.

✅ **Therefore:**
The assumption is false, and there must exist a valid path joining $u$ and $v$.

🌈 **Suitable Example:**

    A ----- B ----- C

**Degrees:**
* Vertex A = 1
* Vertex B = 2
* Vertex C = 1

The odd-degree vertices are A and C. There clearly exists a path $A \to B \to C$ joining them. Hence, the theorem is verified! ✅

🎯 **Final Conclusion:**
If a graph has exactly two odd-degree vertices, then there must be a path connecting them.

The maximum number of edges in a complete graph of 8 vertices is:
$$\frac{8(7)}{2} = 28$$

✅ Maximum Edges = 🌟 **28**

## 🌟 Q3 (ii) “The vertex connectivity of any graph $G$ can never exceed the edge connectivity of $G$.” Justify this.

✨ **Answer:**

🔹 **Definitions:**
* **Vertex Connectivity $K(G)$** = minimum number of vertices whose removal disconnects the graph.
* **Edge Connectivity $\lambda(G)$** = minimum number of edges whose removal disconnects the graph.

🧠 **Important Theorem:**
For every connected graph:
$$K(G) \leq \lambda(G)$$

🌈 **Example: Complete Graph $K_4$**

    A ----- B
    |\     /|
    | \   / |
    |  \ /  |
    |  / \  |
    | /   \ |
    |/     \|
    C ----- D

🔥 **Vertex Connectivity:**
We need to remove at least **3** vertices to disconnect the remaining graph. Hence, $K(G) = 3$.

🔥 **Edge Connectivity:**
We need to remove at least **3** edges to disconnect the graph. Hence, $\lambda(G) = 3$.

🌟 **Verification:**
$K(G) = \lambda(G) = 3$, which perfectly satisfies $K(G) \leq \lambda(G)$. ✅

🧠 **Why This Happens:**
Removing a vertex automatically removes all of its incident edges as well. Therefore, disconnecting a graph using vertex removal is never harder than doing so strictly through edge removal.

✅ **Final Conclusion:**
The vertex connectivity of any graph can never exceed its edge connectivity.

## 🌟 Q5 (ii) How many cards must be selected from a standard deck of 52 cards to guarantee that at least three cards of the same suit are chosen?

A standard deck contains 4 distinct suits: Hearts ❤️, Diamonds ♦️, Clubs ♣️, and Spades ♠️.

🔥 **Worst Case Scenario:**
To delay getting 3 cards of the same suit for as long as possible, you draw exactly **2** cards from each of the 4 suits.
$$\text{Maximum draws without 3 of a suit} = 2 \times 4 = 8 \text{ cards}$$

At this point, you hold 2 cards of each suit. The very next card you pick (**the 9th card**) must belong to one of the 4 suits, immediately creating a set of 3 cards of that suit.

✅ **Final Answer:**
$8 + 1 = 9$
🌟 Minimum cards required = **9**

## 🌟 Q6 (ii) Find the solution of the recurrence relation: $a_n = a_{n-1} + 2a_{n-2}$ with $a_0 = 2, a_1 = 7$.

✨ **Answer:**

🔹 **Step 1: Form the Characteristic Equation**
Rewrite the recurrence relation with all terms shifted to one side:
$$a_n - a_{n-1} - 2a_{n-2} = 0$$

This gives us the characteristic quadratic equation:
$$r^2 - r - 2 = 0$$

🔥 **Step 2: Solve the Quadratic Equation**
Factorize the quadratic expression:
$$(r - 2)(r + 1) = 0$$

The distinct roots are:
$$r = 2, \quad r = -1$$

🔥 **Step 3: State the General Solution**
Since the roots are completely distinct, the general solution takes the form:
$$a_n = A(2^n) + B(-1)^n$$

🔥 **Step 4: Solve for Constants Using Initial Conditions**
* For $a_0 = 2$:
$$A + B = 2$$

* For $a_1 = 7$:
$$2A - B = 7$$

Add the two systems of equations together to eliminate $B$:
$$(A + B) + (2A - B) = 2 + 7$$
$$3A = 9 \implies A = 3$$

Now, substitute $A = 3$ back to solve for $B$:
$$3 + B = 2 \implies B = -1$$

🔥 **Step 5: Formulate the Final Explicit Equation**
Substitute the solved constants $A = 3$ and $B = -1$ back into the general expression:
$$a_n = 3(2^n) - (-1)^n$$

🌈 **Verification:**
* For $n=0$: $3(1) - 1 = 2$ (Correct! ✅)
* For $n=1$: $3(2) - (-1) = 6 + 1 = 7$ (Correct! ✅)

🎯 **Final Conclusion:**
The explicit closed-form solution to the recurrence relation is:
🌟 $$a_n = 3(2^n) - (-1)^n$$
